# 블라인드 풀이 B — 국어 6~7등급 고1 역할

- 읽은 것: `design/review/student_view.md`만, 곡 단위로 끊어 가며 읽음. 정답표·js·기획서·research는 열지 않음.
- 각 문항은 그 문항보다 위에 나온 정보만 써서 풀었음. "답한 뒤 나오는 설명"은 답한 다음에 읽은 것으로 침.
- 학생 설정: 옛한글(ᄒᆞ, ᅀ)이 나오면 일단 겁먹음. 한자는 괄호 속 한글로만 읽음. 긴 카드는 거의 안 읽거나 첫 줄만 봄. 모르면 찍거나 "착해 보이는 보기"를 고름.
- 음보: 게임에서 "몇 음보로 끊는다"는 규칙을 한 번도 못 봤음. 중학교 때 "시조는 4음보"라고 외운 기억이 어렴풋이 있어서, 원문 풀이 줄의 띄어쓰기를 베낀 다음 대충 4덩어리로 맞춤.

## 3. 전체 소감

### 끝까지 할 수 있었을까
- 아마 끝까지는 감. 문제 대부분이 "풀이 줄에 밑줄 친 뜻 = 카드 뜻" 찾기라 한자를 못 읽어도 진행이 됨. 이게 제일 큰 이유.
- 다만 두 군데서 꺾였을 것 같음. 첫 번째는 1부 도입(카드 3개 + Q1 한자 평가문)이고, 두 번째는 2부 도입 Q31(기억력 문제)임. 수업 시간이 끝나 가면 2부 도입에서 그냥 아무거나 눌렀을 것.
- 7곡부터는 패턴(景 빈칸 → 잇기 → 음보 → 한마디)이 익숙해져서 설명 카드를 거의 안 읽고 기계적으로 넘김. 빨리 끝나서 편하긴 했지만 머리에 남은 건 줄어듦.
- 63문항은 한 시간에 하기엔 좀 많게 느껴짐. 특히 잇기 문항 중에 빈칸 문항과 똑같은 걸 한 번 더 묻는 것들(Q7→Q8, Q26→Q27, Q37→Q38, Q43→Q45, Q54→Q55)이 있어서 "또?" 소리가 나옴.

### 제일 짜증 났던 것
1. **음보 끊기**가 제일 짜증 났음. "몇 개로, 무슨 기준으로 끊는지"를 게임이 한 번도 알려 주지 않음(대본에는 "음보로 끊으면 노래가 돼요"뿐임). 원문 띄어쓰기를 베끼면 곡마다 3~6덩어리로 제각각이라, 중학교 때 들은 "4음보"에 대충 맞춰 찍었음. 대본 기준으로는 음보 문항에 답한 뒤 나오는 설명도 없어서, 맞게 끊었는지와 왜 그렇게 끊는지를 끝까지 배울 수 없었음.
2. **옛한글 ᅀ(ᄆᆞᅀᆞᆷ, 이ᅀᅡ)** 같은 글자와 **깨진 글자**. Q27 설명 제목은 "사[ㄹㆍㅁ]과 [ㅎㆍㄴ]가지라", 10곡 카드 제목은 "어듸 가 [ㄷㆍㄴ]니다가"로 보였음. 이건 버그 같음.
3. **칸 수와 카드 수가 안 맞는 문항**. 4곡 Q17은 칸 3개에 카드 2개, 9곡 Q43은 칸 3개에 카드 2개였음. 한 카드를 두 번 쓰는 건지, 칸을 비워 두는 건지 헷갈림.
4. 도입 카드가 길고 연달아 나옴. "실제로는 →"으로 시작하는 부분은 거의 안 읽었음.

### 다 하고 나서 기억나는 작품 내용 (대본 다시 안 보고 5가지)
1. 자연을 너무 좋아하는 게 고칠 수 없는 병(천석고황)이라서, "고쳐서 뭐 하냐"고 함.
2. 자연 속에 있어도 "저 아름다운 한 사람(피미일인)" = 임금을 못 잊음.
3. 천둥이 쳐도 귀먹은 사람은 못 듣고 해가 떠도 눈먼 사람은 못 봄. 이게 도를 못 깨닫는 사람 비유고, "우리는 그러지 말자"는 내용.
4. 옛 성현은 못 만나도 그분들이 가던 길(녀던 길)이 앞에 있으니 따라가겠다는 내용.
5. 청산은 늘 푸르고 물은 밤낮 안 그치니 우리도 공부를 그치지 말자(만고상청).
- (흐릿한 것: 앞 6곡이 언지, 뒤 6곡이 언학이라는 건 기억나는데 둘 중 뭐가 "뜻"이고 뭐가 "배움"인지 헷갈림. 흰 망아지가 누구인지는 기억 안 남. 마지막 곡이 "쉽고도 어렵다"였던 건 어렴풋함.)

### "요령으로 맞힌" 문항 목록
- **착해 보이는 보기 / 국어 답처럼 생긴 보기**: Q1의 ③, Q11, Q16, Q30, Q40, Q47, Q53, Q58, Q61, Q63
- **고전 공식("님·한 사람 = 임금")**: Q18
- **보기 소거 / 제일 길고 구체적인 보기**: Q25, Q56
- **남은 것끼리 반쯤 찍음**: Q31(2곡·3곡)
- **그냥 찍음**: Q1의 ①②, Q5 중장, Q10, Q23, Q29, Q35 중장, Q52, Q62 (음보 문항은 대부분 기준 없이 찍음)
- 참고: "이 노래에 담긴 화자의 마음을 한마디로" 문항 12개(Q6·11·16·20·25·30·36·42·47·53·58·63)는 오답 보기가 원망·서러움·욕심·피곤함·자랑·불평처럼 티 나게 나빠서, 작품을 안 읽어도 "제일 바른 말"만 고르면 다 맞힐 수 있을 것 같음. 실제로 나는 풀이를 보고 골랐지만, 요령만으로도 충분했음.
